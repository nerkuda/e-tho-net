# Ручной вход в базу знаний ETN

Ярлык для ручного запуска (`/etn-kb`). В обычной работе не вызывается:
AGENTS.md репозитория уже требует входить в базу знаний напрямую.

## Что сделать

1. Войди в базу по точке входа из `AGENTS.md` проекта (раздел «База знаний —
   основной источник»): один вызов `etn.comments.get` для корневой мысли.
2. Дальше работай по нему: перед задачей — мысль-инструкция по своей ситуации
   из раздела «Инструкции агентам», после задачи — отчёт.

Точка входа и карта разделов сознательно не дублируются здесь: источник
истины один — `AGENTS.md`, содержание — сама база.

## Если база недоступна

Не заводи новые сущности вслепую и не «вспоминай» инструкции по памяти —
остановись и сообщи. Аварийный минимум — в `AGENTS.md` (§7).
