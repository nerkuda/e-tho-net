# Установка десктоп-клиента ETN

Клиент — приложение на Electron (Windows 10/11 x64, macOS, Linux x64).
Онлайн-only: работает только при связи с сервером.

## 1. Установка

1. Скачайте установщик для вашей ОС из релизов проекта (Windows: `ETN-Setup-*.exe`;
   macOS: `ETN-*.dmg`; Linux: `ETN-*.AppImage` или `.deb`).
2. Установите обычным способом.

Для разработки: `npm install && npm run dev:client` в корне монорепо.

## 2. Первый запуск и подключение

1. При первом запуске открывается экран подключения:
   - **Адрес сервера** — `http(s)://host:port` (например, `https://etn.example.com`).
   - **API-key** — ключ, выданный администратором (см.
     [install-server.md](install-server.md), §3).
2. Кнопка «Подключиться» проверяет ключ (`GET /me`). При ошибке — понятное
   сообщение (неверный ключ / сервер недоступен / несовместимая версия).
3. После подключения открывается список доступных мыслесетей.
4. Профиль (адрес сервера + зашифрованный ключ) сохраняется локально; ключ
   шифруется средствами ОС (DPAPI/Keychain/libsecret) и **не покидает** главного
   процесса приложения.

## 3. Подключение к другому серверу

Меню пользователя → «Сменить сервер» → ввести другой адрес и ключ. Несколько
профилей могут сосуществовать.

## 4. Ограничения MVP

- **Нет офлайна.** При разрыве связи приложение показывает 🔴 и блокирует
  сохранение; несохранённые правки сохраняются в черновики и отправляются после
  восстановления соединения.
- Вложения — ссылки (URL) или пути к файлам на этом компьютере; файлы на сервер
  не загружаются.
- Экспорт в PDF пока недоступен (используйте HTML + печать).
