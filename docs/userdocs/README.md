# Руководство пользователя ETN

Руководство по работе с ETN — The Endless Thought Network. Тексты живут в
базе знаний ETN и **генерируются в этот каталог** при выпуске каждой версии;
вручную файлы руководств не правятся (правки теряются при пересборке).
Единственное исключение — этот README.

## С чего начать изучение

Если вы впервые видите ETN, читайте в таком порядке:

1. [Обзор и основы](overview.md) — что такое ETN, базовые понятия (мысль,
   связь, тип, свойство, комментарий), окно программы, поиск и общие механизмы.
2. [Установка и обновление](install.md) — установка сервера и клиента,
   подключение, обновление.
3. [Карта — рабочий стол](map.md) — главный экран: зоны холста, навигация,
   перетаскивание мыслей, полоса отборов.
4. [Структуры — рабочий стол](structures.md) — отборы и деревья мыслей,
   панель выделения и групповые операции.
5. [Дневник — рабочий стол](diary.md) — лента датированных записей с
   привязками к мыслям.
6. [Редактор](editor.md) — карточка мысли/связи: комментарий (markdown,
   трансклюзии, команды), свойства, вложения, типы, удаление и корзина.
7. [События и совместная работа](events.md) — журнал активности, авторство,
   захваты объектов при совместном редактировании.
8. [Публикации](publications.md) — живые документы из мыслесети: библиотека,
   полки, чтение, настройка, экспорт.
9. [Слои изменений](layers.md) — черновики поверх основы: когда заводить,
   работа в слое, слияние и конфликты.
