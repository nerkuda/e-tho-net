# ETN — обзор и основы

**Автор:** Проект ETN

Назначение ETN, базовые понятия, окно программы, рабочие столы, поиск, горячие клавиши и общие механизмы.

<a id="pub-50bb672a"></a>

## Горячие клавиши

### Общие

| Клавиши | Действие |
| --- | --- |
| `Ctrl+Shift+F` | глобальный поиск по сети (на карте мыслей) |
| `Ctrl+F` | поиск внутри текущего текстового поля (например, комментария) |
| `Ctrl+клик` | добавить/убрать мысль из выделения |
| `Ctrl+клик` по эллипсу | выделить всех родителей или детей |
| `Ctrl+наведение` | предпросмотр содержимого |
| `Ctrl+C` / `Ctrl+V` | копировать / вставить мысль |
| `Escape` | закрыть верхний диалог / снять выделение / снять рамку курсора |

### На карте мыслей

| Клавиши | Действие |
| --- | --- |
| стрелки | перемещать рамку-курсор по облачкам |
| `Tab` / `Shift+Tab` | как стрелки вправо / влево |
| `Home` / `End` | первое / последнее облачко зоны |
| `Enter` | открыть мысль курсора в редакторе |
| `Ctrl+Enter` | перевести мысль курсора в фокус |
| `Ctrl+Shift+←/→` или `Ctrl+Shift+↑/↓` | перестановка в ручном порядке зоны |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | масштаб холста: больше / меньше / 100% |

### В диалогах

| Клавиши | Действие |
| --- | --- |
| `Enter` / `Ctrl+Enter` | подтвердить |
| `Escape` | закрыть без применения |
| `Shift+Enter` | применить, не закрывая (в настройках) |

### Редактирование комментария

У поля комментария есть свои команды: `Ctrl+B` — жирный, `Ctrl+I` — курсив, `Ctrl+U` — подчёркнутый, `Ctrl+S` — зачёркнутый, `Ctrl+Alt+1/2/3` — заголовки, `Ctrl+Shift+7/8/9` — списки, `Ctrl+Shift+Q` — цитата, `Ctrl+Shift+K` — блок кода, `Ctrl+F` / `Ctrl+H` — поиск и замена в поле. Сочетания можно менять в настройках поля комментария.

`Ctrl+колесо` над markdown-полем масштабирует документ (не холст).

## История посещений

Единая история для всех рабочих столов (карта, структуры, дневник). В неё попадают мысли, **открытые в редакторе**, независимо от экрана и способа открытия. Связи в историю не попадают.

### Где находится

В статус-баре — мини-облачка последних мыслей (самые свежие слева) и раскрывающийся список с остальной историей. Глубина — до 50 мыслей.

### Как пользоваться

- **Клик** по облачку: на карте мыслей — переход в фокус; в структурах и дневнике — открытие в редакторе.
- **Перетаскивание** элемента истории на холст действует как обычное облачко (создать связь, `Ctrl` — переподчинить, бросить в зону — связать с фокусом). Бросок мысли на панель истории открывает её.
- Правый клик по элементу истории — обычное контекстное меню мысли.

### Видимость

Помеченные на удаление скрываются, если в настройках сети выключено «Показывать содержимое корзины»; неактуальные — если выключен показ неактуальных.

## Копирование и вставка мыслей

### Копирование

- `Ctrl+C` копирует одну мысль: на карте — мысль под курсорной рамкой, без рамки — открытую в редакторе. Содержимое панели выделения на это не влияет. Если в этот момент выделен текст (например, при просмотре комментария) — копируется текст.
- «Скопировать мысли» (меню «Действия» панели выделения) копирует несколько мыслей вместе со связями между ними.

### Вставка

- `Ctrl+V` на карте вставляет копию под мыслью курсорной рамки (или под фокусом): копия получает новый идентификатор, связи внутри скопированного набора сохраняются, родителем становится цель — только у «корня» набора.
- `Ctrl+V` в поле ввода диалога добавления: UUID — поиск и связь, строка `Имя | синонимы` — новая мысль, многострочный текст — по мысли на строку.

### Между мыслесетями

Копирование работает и через табы в одном окне, и между окнами. Типы, свойства и типы связей подбираются в сети-получателе по идентификатору, затем по имени; ненайденное сбрасывается.

Во внешний буфер обмена при копировании попадает только текст внутренних ссылок, поэтому содержимое мыслей наружу не утекает; когда буфер перезаписала другая программа, вставка из ETN больше не срабатывает.

## Настройки клиента

Открыть настройки можно из меню «Вид» → «Все настройки» (иконка шестерёнки). Пункт «Настройки мыслесети» из меню «Мыслесеть» открывает тот же диалог, но сразу на разделе «Мыслесеть».

### Разделы

**Пользователь**

- «Имя для отображения» — как вас видят другие участники;
- «Логин» — только для чтения.

**Мыслесеть**

- «Название сети»;
- самоописание сети (Описание / Когда использовать / Правила / Примеры) — редактирует только владелец, остальным доступно чтение;
- «Узловой тип раздела» — тип мыслей, задающий структуру разделов сети;
- «Видимость»: «Показывать неактуальные мысли и связи» и «Показывать содержимое корзины в этой сети».

**Клиент**

- «Тема» — светлая или тёмная, применяется сразу;
- «Размер облачка» — ширина и отступ.

**Логирование**

- включение журналов для диагностики; переключатели применяются сразу.

### Кнопки

- «Применить» (`Shift+Enter`) — применить, не закрывая диалог;
- «Применить и закрыть» (`Ctrl+Enter`);
- «Отменить» (`Esc`).

Если сервер вернул ошибку, её текст появится в строке внизу диалога, а сам диалог останется открытым.

## Окно программы

Окно ETN сверху вниз устроено так.

### Табы (верхняя строка)

Лента вкладок: каждая — отдельная открытая мыслесеть со своим контекстом (фокус, вид, фильтры, история). Одну сеть можно открыть в нескольких табах — состояния независимы.

- **«+»** — открыть экран списка сетей (выбрать существующую или создать новую).
- Табы можно перетаскивать, меняя порядок; не поместившиеся уходят в список `▾ N`.
- `*` в заголовке таба — по сети пришли изменения (не от вас); снимается при активации таба.
- Если доступ к сети потерян, таб бледный, а при активации показана заглушка «Нет доступа к сети».
- Закрытие последнего таба возвращает на экран списка сетей.

Справа от табов — подменю пользователя.

### Панель инструментов

Слева направо:

- **Меню пользователя** — «Открыть сеть», «Создать сеть», «Администрирование» (только администратору), «Настройки», «О программе», «Отключиться».
- **Меню «Мыслесеть»** — команды текущей сети: «Участники сети» (владельцу), «Выйти из сети», «Типы мыслей», «Типы связей», «Свойства и связи», «Корзина (N)», «Настройки мыслесети».
- **Меню слоёв** — работа со слоями изменений.
- **Переключатель рабочих столов** — Карта мыслей / Структуры мыслей / Дневник / События.
- **Панель закреплённых мыслей** — чипы для быстрого перехода.
- **Меню «Вид»** (справа) — «Показать/Скрыть редактор» и «Все настройки».

### Строка поиска

Находится под панелью инструментов и принадлежит рабочему столу «Карта мыслей»; в других видах скрыта.

### Рабочая область

- **Панель выделения** (слева) — появляется, когда есть выделенные мысли.
- **Холст** (центр) — окрестность мысли в фокусе; в других рабочих столах заменяется пространством вида.
- **Редактор** (справа) — положение настраивается, общий для всех видов.

### Статус-бар (нижняя строка)

- индикатор соединения: 🟢 подключено, 🟡 переподключение, 🔴 нет связи;
- имя сети;
- история посещений (мини-облачка и раскрывающийся список);
- количество мыслей в сети;
- последнее событие сети (исчезает через несколько секунд или по клику);
- при конфликте версий — предупреждение «изменено другим пользователем» с кнопкой «показать»;
- масштаб холста (при изменении).

## Поиск

**Глобальный поиск** по сети вызывается по `Ctrl+Shift+F` и работает только на рабочем столе «Карта мыслей» — строка поиска расположена под панелью инструментов. В видах «Структуры мыслей» и «Дневник» строка скрыта.

> `Ctrl+F` теперь ищет внутри текущего текстового поля (например, в поле комментария), а не по всей сети.

### Как искать

1. Нажмите `Ctrl+Shift+F` и введите запрос. Предыдущий запрос восстанавливается.
2. Результаты группируются: **имена**, **тексты**, **связи**, **хронология**. Совпадения подсвечиваются.
3. `Enter` повторяет поиск; выберите запись стрелками и откройте её — мысль откроется, а результат по связи или хронологии покажет свой объект.

Если ввести идентификатор мысли в виде UUID, поиск найдёт её напрямую.

### Фильтры (шестерёнка)

- искать только в подчинённых мыслях;
- типы мыслей и типы связей;
- автор и редактор;
- показывать неактуальные;
- показывать помеченные на удаление (по умолчанию помеченные скрыты).

Панель закрывается по `Escape` или клику вне неё.

<a id="pub-cff7a443"></a>

## Предпросмотр содержимого

Наведение курсора с зажатым `Ctrl` раскрывает содержимое во всплывающем окне рядом — без открытия редактора. Работает на всех экранах и во всех списках: карта, структуры, дневник, поиск, история, закреплённые, панель выделения.

### Что можно посмотреть

- на индикаторы облачка: 📝 — постоянный комментарий, 📅 — список хронологических записей, 📎 — список вложений;
- на **ссылки внутри комментария**: на мысль — её постоянный комментарий, на мысль из другой мыслесети — имя сети, на файл — картинку или текст, прочие ссылки — адрес;
- на **эллипсы облачка** — входящие и исходящие связи; клик по мысли в списке открывает её в редакторе, двойной — переводит в фокус;
- на **иконку-картинку** — «лупу» с полной картинкой.

### Как ведёт себя окно

- курсор можно перевести внутрь окна — оно закрывается не сразу после ухода курсора, поэтому успевает раскрыться;
- содержимое прокручивается, предпросмотры вкладываются друг в друга;
- окно закрывается, когда курсор уходит из его границ; `Esc` закрывает верхнее окно.

## Что такое ETN и базовые понятия

**ETN — графовая база знаний.** Это «цифровой мозг»: сеть связанных записей-мыслей с комментариями, вложениями и совместной работой нескольких участников в реальном времени.

### Из чего состоит

- **Мыслесеть** — отдельная база мыслей и связей. В одном окне можно открыть несколько мыслесетей — каждая в своём табе.
- **Мысль** — запись: человек, организация, идея, тема, гипотеза — всё, что нужно связать. У мысли есть название, синонимы для поиска, тип, комментарий, вложения и связи.
- **Связь** — направленное отношение между мыслями. У связи два имени — для прямого и обратного направления («состоит из» ↔ «входит в состав»).
- **Тип** — шаблон для мыслей и связей: задаёт внешний вид и набор свойств. Типы образуют иерархию и наследуют друг друга.
- **Свойство** — именованное поле мысли или ребра связи: текст, число, дата, ссылка на мысль и другое. Свойства вида «связь» соединяют мысли: заполняя такое свойство, вы создаёте типизированную связь.
- **Комментарий** — содержимое мысли. **Постоянный** комментарий — основной текст (markdown: заголовки, списки, ссылки, картинки); **хронологические** записи — датированные заметки по мысли.

### Индикаторы на облачке мысли

📝 — есть постоянный комментарий, 📅 — есть хронологические записи, 📎 — есть вложения.

### Состояния мыслей

Мысль может быть **актуальной** или **неактуальной**; лишние мысли помечаются в корзину.

### Куда дальше

- Устройство экрана — страница «Окно программы».
- Работа с картой — каталог «Карта — рабочий стол».

## Добавление мыслей

### Способы добавить мысль

1. Правый клик по мысли → «Добавить родительскую мысль» / «Добавить дочернюю мысль».
2. Потянуть за **верхний эллипс** облачка (создать родителя) или **нижний** (создать ребёнка) и отпустить на пустом месте.
3. Двойной клик по пустому месту зоны «Верх слева» (родитель) или «Низ» (ребёнок). В зоне «Верх справа» добавления нет — у фокуса может быть несколько родителей.
4. Правый клик по зоне → «Добавить мысль» (для зон «Верх слева» и «Низ»).
5. Перетащить ссылку или файл из браузера на холст — создастся мысль с вложением (файл загрузится на сервер).

### Диалог добавления

- Начните вводить название — ETN ищет существующие мысли по имени и синонимам, чтобы не плодить дубликаты. Выберите найденную или создайте новую.
- Идентификатор (UUID) в поле ввода ищет мысль по нему напрямую.
- **Синонимы** вводятся через `|`: `Иванов Иван | Ваня, Иваныч`. В синонимах можно использовать `*` — «любое число символов в пределах одного слова».
- **Поле «Свойство связи»** (в диалоге с карты) позволяет сразу задать осмысленную типизированную связь: выберите нужную сторону свойства (например, «запланировано в версию»), и связь попадёт в типизированное свойство, а не останется простой структурной.
- **Охват поиска** — переключатель в шапке диалога: «текущая сеть» или «по всем сетям». Создание новых мыслей всегда идёт в текущей сети.

### Несколько мыслей сразу

- Включите режим **«несколько»**, вводите по одной (`Enter`), в конце `Ctrl+Enter`.
- Можно вставить многострочный текст — каждая строка станет мыслью.
- `Ctrl+Shift+Enter` — вставить всё и сразу открыть первую из добавленных мыслей в фокусе.

Если в поле типа совпадений нет, список предложит «Создать новый „…“» — откроется диалог создания типа с предзаполненным именем.

## Закреплённые мысли

Панель закреплённых мыслей — в верхней строке, справа от кнопок рабочих столов: чипы для быстрого перехода из любого места приложения. Список хранится на сервере — на всех ваших компьютерах он один.

- **Закрепить/открепить**: правый клик по мысли в любом отображении → «Закрепить мысль» / «Открепить мысль». Можно просто перетащить мысль на панель — она подсветится рамкой, а метка покажет место вставки; перетаскивание между чипами меняет порядок.
- **Переход**: клик по чипу — на карте это фокус и редактор, в структурах — открытие в редакторе.
- **Предел** — не более 20 закреплённых; сверх лимита программа попросит сначала открепить лишние.
- **Вынос чипа** на холст мысль не открепляет — для этого есть команда «Открепить».
- Не поместившиеся чипы уходят в список `▾ N`. Пустая панель показывает подсказку «закрепите мысль».
- Неактуальные закреплённые скрываются вместе с настройкой показа неактуальных; удалённая мысль покидает панель; помеченные на удаление скрываются при выключенной настройке показа корзины. Сам список на сервере при этом не чистится.

<a id="pub-736c1d2a"></a>

## Неактуальные мысли

Мысль или связь можно пометить **неактуальной**, когда она отработана или перестала быть действительной, но важна как часть истории. В отличие от корзины, неактуальная мысль остаётся в сети — она просто скрывается по настройке.

- **Пометить/снять**: правый клик по мысли или связи → «Изменить актуальность».
- **Показ** включается в настройках видимости — «Показывать неактуальные мысли и связи» — персонально для каждой сети.
- Настройка действует на холст и поиск, а также на панель закреплённых мыслей и историю посещений: при скрытии неактуальные чипы и облачка прячутся.

## Рабочие столы: карта, структуры, дневник

Рабочие столы переключаются кнопками-иконками в верхней строке. Общими для всех остаются панель редактора, панель выделения, панель закреплённых мыслей и статус-бар.

- **Карта мыслей** — холст с мыслью в фокусе и её окружением, строка поиска и весь функционал холста.
- **Структуры мыслей** — отбор мыслей по критериям (ключевые слова, типы, свойства, типы связей, автор/редактор) и дерево результатов.
- **Дневник** — дневниковые записи с календарём месяца и лентой по дням, привязками записей к мыслям и связям, панелью отбора и поиском.
- **События** — лента сетевых событий «кто что сделал»: создано, изменено, удалено, помечено в корзину и т. п.; фильтры по периоду, участнику и типу сущности.

Строка поиска и `Ctrl+Shift+F` действуют только на карте мыслей; в «Структурах» и «Дневнике» строка скрыта.

Активный рабочий стол запоминается отдельно на каждом клиенте и восстанавливается при открытии сети.

## Экспорт и импорт

### Выгрузка в читаемый документ

Выделите мысли (`Ctrl`+клик) → панель выделения слева → меню «Действия» → «Экспорт» → формат Markdown или HTML. Документ собирается из заголовков, комментариев и связей выбранных мыслей.

### Перенос между сетями и компьютерами: формат `.etnx`

Для переноса мыслей между разными мыслесетями и компьютерами используется архив `.etnx`. Его ключевое свойство: **импорт — не добавление копий, а слияние по тождеству мыслей**, поэтому повторный импорт того же архива не плодит дубликаты.

- **Экспорт**: выгружается срез графа. Опции управляют составом — включать ли типы, хронологию, вложения и подчинённые мысли (и на какую глубину). По умолчанию типы и хронология включены, вложения и подчинённые — выключены.
- **Импорт**: результат кладётся в текущий выбранный контекст целевой сети (основу или слой).

#### Что переносится, а что нет

- идентификаторы мыслей сохраняются как есть;
- авторство переписывается на вас, исходный автор остаётся только в истории архива;
- актуальность сохраняется как есть;
- флаги корневой и защищённой мысли сбрасываются — у целевой сети они свои;
- личные данные (история посещений, закрепления, сохранённые отборы, настройки фокуса) не переносятся;
- вложения переносятся только при включённой опции;
- цвет и вид иконки типов не переносятся — это известное ограничение.

#### Слой и экспорт

Экспортируется то, что выбрано в данный момент: основа — так основа; слой — его разрешённое состояние. Импорт, в свою очередь, попадает в текущий выбранный слой или основу.

### Резервное копирование

Резервное копирование и снапшоты сети — это работа с файлами баз целиком, а не с отдельными мыслями.
