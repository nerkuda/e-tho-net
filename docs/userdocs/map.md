# ETN — карта (рабочий стол)

**Автор:** Проект ETN

Рабочий стол «Карта»: зоны холста, навигация, перетаскивание, ручной порядок, полоса отборов.

<a id="pub-ce04d7fc"></a>

## Карта мыслей (рабочий стол)

**Карта мыслей** — основной рабочий стол ETN: холст с мыслью в фокусе в центре и её окружением вокруг.

### Зоны холста

| Зона | Что показывает |
| --- | --- |
| Центр | мысль в фокусе |
| Верх слева | источники связей фокуса (родители) |
| Верх справа | родственные мысли — у которых есть общий родитель с фокусом |
| Низ | назначения связей фокуса (потомки), во всю ширину |

Мысль показывается не более чем в одной зоне.

### Управление

- **Клик** по облачку — открыть мысль в редакторе (вокруг неё появляется ореол).
- **Двойной клик** по облачку — перевести в фокус.
- **Двойной клик** по пустому месту зоны «Верх слева» или «Низ» — открыть диалог добавления родительской или дочерней мысли. В зоне «Верх справа» добавления нет.
- **Правый клик** по зоне — «Добавить мысль» (только «Верх слева»/«Низ») и выбор сортировки зоны.
- **Правый клик** по облачку — контекстное меню мысли.

### Границы и подгрузка

- Разделители между зонами можно перетаскивать, меняя их размер; двойной клик по разделителю возвращает пропорции по умолчанию.
- Фокус-ряд подсвечен горизонтальной полосой.
- В правом верхнем углу каждой зоны — число мыслей в ней. При прокрутке зоны её содержимое подгружается по мере необходимости.

<a id="pub-0cd26e12"></a>

## Навигация по холсту

### Мышью

- **Клик** по облачку — открыть мысль в редакторе; **двойной клик** — перевести в фокус.
- **Правый клик** по облачку — контекстное меню мысли; по зоне — добавить мысль и выбрать сортировку зоны.
- **Прокрутка колесом** в зоне — вертикальная; содержимое зоны подгружается дальше по мере прокрутки.

### Масштаб

| Клавиши | Действие |
| --- | --- |
| `Ctrl+=` / `Ctrl++` | увеличить на 5% |
| `Ctrl+-` | уменьшить на 5% |
| `Ctrl+0` | сбросить до 100% |

Масштаб меняется в диапазоне 50–200%, показывается в статус-баре и сохраняется. `Ctrl+колесо` над полем комментария масштабирует документ, а не холст.

### Клавиатурой

Навигация доступна, пока фокус клавиатуры на холсте (клик мышью по холсту или облачку оставляет его там).

| Клавиши | Действие |
| --- | --- |
| стрелки | переместить рамку-курсор на ближайшее облачко в направлении стрелки |
| `Tab` / `Shift+Tab` | как стрелка вправо / влево |
| `Home` / `End` | первое / последнее облачко зоны; с фокус-облачка — край первой / последней непустой зоны |
| `Enter` | открыть мысль курсора в редакторе |
| `Ctrl+Enter` | перевести мысль курсора в фокус |
| `Ctrl+Shift+←/→` | переставить мысль в порядке зоны (при ручном порядке) |
| `Escape` | снять рамку курсора |

Курсор сбрасывается при смене фокуса.

### Сортировка зоны

Правый клик по зоне → выбор порядка: по алфавиту, по дате создания, по дате просмотра, ручной (для «Верх справа» ручной недоступен). Подробности о ручном порядке — на странице «Ручной порядок в зоне».

## Перетаскивание мыслей на холсте

Перетаскивать можно облачко любой зоны и фокус-облачко.

### Обычное перетаскивание

- на **верхний эллипс** мысли — создать связь, где перетаскиваемая становится родителем;
- на **тело или нижний эллипс** — создать связь в обратном направлении;
- в **соседнюю зону** (между родителями и потомками) — переместить мысль, развернув её связи с фокусом;
- порядок мыслей при обычном перетаскивании **не меняется**.

### С модификаторами

- **`Ctrl` + перетаскивание** на мысль — сделать её единственным родителем перетаскиваемой (переподчинить, не копировать).
- **`Ctrl+Shift` + перетаскивание** (при сортировке зоны «ручной») — поставить мысль перед другой; остальные сдвигаются, место показывается зазором.

### Эллипсы облачка

- Потянуть за **верхний эллипс** — создать родителя, за **нижний** — создать ребёнка; отпустить на другой мысли — связать с ней.
- Наведение на эллипс подсвечивает все связи соответствующего направления.

### Другие цели броска

- на **панель закреплённых мыслей** — закрепить;
- на **панель истории** — открыть мысль;
- в **поля значений свойств и панели отбора** в редакторе — подставить мысль.

### Отмена

`Esc` во время перетаскивания отменяет жест.

## Ручной порядок в зоне

По умолчанию мысли в зоне упорядочены автоматически. Порядок **«ручной»** позволяет задать его самому — в зонах «Верх слева» (родители) и «Низ» (потомки). В зоне «Верх справа» ручной порядок недоступен.

### Включение

Правый клик по зоне → список сортировки → **ручной**. Направление всегда «сверху вниз».

### Перестановка

- **`Ctrl+Shift` + перетаскивание** облачка на другую мысль — поставить перед ней; остальные сдвигаются, после броска облачка плавно переезжают.
- **`Ctrl+Shift+←/→`** на карте — переставить мысль курсора в порядке зоны.

### Обозначение номера

В правом нижнем углу облачка выводится порядковый номер. Новые мысли номер не получают до явного переставления.

Порядок сохраняется для мысли в фокусе: вернётесь к ней — он восстановится. Обычное перетаскивание порядок не меняет.

## Полоса отборов под фокусом

Под облачком фокуса расположен узкий ряд кнопок — **полоса отборов**. Она переключает, что показывает нижняя зона холста: обычных потомков фокуса или результат именованного отбора его типа мысли.

**Отбор** — это способ увидеть содержимое, заданное типом: «Работы этой версии», «Спеки этого тех.проекта», «Все мысли этого автора за неделю» и любое другое, что задал автор типа.

### Кнопки слева направо

- **«Потомки»** — обычное содержимое нижней зоны, прямые потомки фокуса. Всегда первая.
- **Отборы типа** — по кнопке на каждый именованный отбор типа фокуса (включая унаследованные от родительских типов). Не поместившиеся уходят в меню `⋯`.
- **«+»** — добавить отбор к типу. У мысли без типа кнопка недоступна.
- **Кнопка-воронка** (справа) — фильтр типов связей на холсте: какие типы связей участвуют в зонах и линиях.

### Как это работает

- Активна ровно одна кнопка. При переводе мысли в фокус открывается отбор, помеченный у типа как «по умолчанию»; если такого нет — «Потомки».
- Результат отбора показывается в нижней зоне теми же облачками, но без действий, осмысленных только для потомков: ручной порядок и добавление мысли двойным кликом по пустому месту недоступны.
- Если условие отбора не разрешилось, зона остаётся пустой и объясняет причину текстом.

### Контекстное меню кнопки

Правый клик по кнопке отбора — «Изменить отбор» / «Удалить отбор» (правка типа, влияет на все мысли этого типа). У кнопки «Потомки» контекстного меню нет.
