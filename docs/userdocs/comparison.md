## Сравнение ETN с TheBrain и Obsidian

ETN находится в одном семействе с TheBrain и Obsidian: персональное управление знаниями, построенное вокруг связей, а не папок. Архитектурные решения у них разные, и эта страница описывает их без оценок «лучше — хуже»: каждый инструмент подходит своему способу работы.

| | ETN | TheBrain | Obsidian |
|---|---|---|---|
| Где живут данные | На вашем сервере (домашний компьютер или VPS); каждая мыслесеть — база SQLite плюс файлы вложений | Настольное приложение с облачной синхронизацией | Локальное хранилище Markdown — папка с файлами |
| Основная модель | Направленный граф мыслей: мысль — узел, связь — типизированное ребро | Направленный граф мыслей (плекс) | Заметки в Markdown, соединённые ссылками |
| Типизация | Типы мыслей и связей со свойствами, наследованием и отборами на уровне типа | Типы мыслей и теги | Заметки, теги и свойства Markdown; связи по умолчанию не типизированы |
| Совместная работа | Несколько человек и AI-агентов правят одну базу в реальном времени, включая слои изменений | Синхронизация между устройствами | Файлы через сервис синхронизации или git; встроенного совместного редактирования нет |
| AI-агенты | Встроенный MCP-сервер: помощники ищут, ориентируются, пишут и связывают мысли | — | Внешние плагины и инструменты; встроенного MCP-сервера нет |
| Управляемые изменения | Слои изменений: ветка графа, сливаемая в основу после проверки | — | Git или копии файлов |
| Выпуск документов | Публикации, собираемые из мыслей; экспорт в Markdown/HTML/PDF | — | Экспорт на основе Markdown и генераторы статических сайтов |
| Мобильные приложения | Нет, в планах | Есть (iOS, Android) | Есть (iOS, Android) |
| Лицензия и цена | MIT, всё бесплатно и self-hosted | Приложение бесплатно; облачные сервисы — по подписке | Бесплатно для личного использования, платная лицензия для компаний |

**TheBrain** — прямой источник вдохновения для ETN (см. историю создания). Плекс — карта, где мысль является узлом, а связь — линией, — основной способ перемещения по знаниям; ETN сохраняет эту идею и добавляет сервер, общий для людей и агентов, типизированные связи и свойства, общие между типами, слои изменений и встроенный MCP-сервер.

**Obsidian** устроен вокруг локального хранилища Markdown-файлов: легковесного, переносимого, легко бэкапящегося любым файловым инструментом. ETN хранит мысли в базе: мысль — не файл, а узел, который несёт постоянный комментарий, вложения, свойства, датированные записи и любое число типизированных связей. Markdown остаётся форматом текста внутри мысли — с трансклюзиями и живым предпросмотром, а дневник работает как daily notes, но всё это живёт в одном графе. Встроенного импорта из Obsidian или TheBrain в ETN нет; миграцию берут на себя агенты через MCP.

**Чем ETN не пытается быть.** Это не хостинговый сервис, и он не синхронизирует данные через чужое облако: сервер запускаете вы, файл принадлежит вам. ETN и не претендует на замену простого файлового заметочника — если папки Markdown-файлов вам достаточно, проще взять Obsidian.
