# Руководство пользователя ETN

ETN — «цифровой мозг»: граф связанных записей (мыслей) с комментариями,
вложениями и совместной работой в реальном времени.

## 1. Базовые понятия

- **Мыслесеть** — отдельная база мыслей и связей (аналог «мозга» в TheBrain).
- **Мысль** — запись: люди, организации, идеи, темы, гипотезы… Всё, что вы хотите
  связать.
- **Связь** — направленное отношение между мыслями («состоит из» → «входит в
  состав»). Имеет имена для обоих направлений.
- **Холст** — экран с мыслью в фокусе и её окружением.
- **Фокус** — мысль в центре холста.
- **Закреплённая мысль** — мысль, вынесенная на верхнюю строку приложения для
  быстрого перехода (раздел 2).

## 2. Навигация по холсту

Холст делится на зоны:

| Зона | Что показывает |
|------|----------------|
| Центр | мысль в фокусе |
| Верх слева | источники связей (родители) |
| Верх справа | родственные мысли (те же родители) |
| Низ | назначения связей (дети) |

- **Клик по мысли** → она становится фокусом.
- **Двойной клик по пустому месту зоны** «Верх слева»/«Низ» открывает диалог
  добавления родительской/дочерней мысли (к фокусу); одиночный клик по пустому
  месту ничего не открывает. В зоне «Верх справа» добавления нет: у фокуса
  может быть несколько родителей.
- **Прокрутка** в зоне — вертикальная; на полосе виден диапазон `12–36`.
- **Меню зоны:** правый клик по зоне → «Добавить мысль» (для «Верх слева» и
  «Низ» — как клик по пустому месту) и сортировка (алфавит, дата создания,
  дата просмотра, ручной). Ручной — перетаскиванием облачков с зажатыми
  `Ctrl`+`Shift` или клавишами `Ctrl`+`Shift`+`↑/↓`; направление всегда
  «сверху вниз по порядку зоны» (переключатель возр/убыв для ручного
  режима не показывается).
- **Раскладка в зоне** — построчно (row-major): первая мысль в левом-верхнем
  углу, последняя — в правом-нижнем; между ними облачка идут слева
  направо, потом переход на следующую строку.
- **Номера при ручном порядке:** в правом нижнем углу облачка (кружок
  слегка перекрывает угол) выводится порядковый номер мысли в зоне
  (1-based). Обновляется автоматически при любых изменениях состава
  зоны (добавление, удаление, отвязка связи). Новые мысли номера не
  получают — индикатор для них скрыт до явного переставления.
- **Перетаскивание мысли:** обычное — на другую мысль создаёт связь (на
  верхний эллипс — A→Б, на тело — Б→A), в соседнюю зону — перемещает мысль
  между родителями и детьми фокуса; `Ctrl`+перетаскивание на мысль — сделать
  её единственным родителем перетаскиваемой (не копия); `Ctrl`+`Shift`+
  перетаскивание (при «ручном» порядке) — поставить перед мыслью: место
  вставки показывается зазором, облачка раздвигаются и после броска плавно
  переезжают.
- **История фокуса** — в статус-баре: 3 последних мысли + список `▾`. Клик
  возвращает к прежней мысли (глубина — 50).
- **Поиск** — `Ctrl+F`; строка поиска — на карте мыслей, под верхней строкой
  программы. Восстанавливает предыдущий запрос. Результаты по группам:
  имена / тексты / связи / хронология. Шестерёнка — фильтры (только в
  подчинённых, типы мыслей/связей, показывать неактуальное).

### Закреплённые мысли

На верхней строке приложения, справа от кнопок «Карта мыслей»/«Структуры
мыслей», — панель закреплённых мыслей **во всю свободную ширину**: чипы с
иконками в одну строку; не поместившиеся — в списке `▾ N`.

- **Закрепить/открепить** — правый клик по мысли в любом месте (холст,
  структуры, история, выделение) → «Закрепить мысль»/«Открепить мысль».
  Можно просто перетащить мысль на панель — панель подсветится рамкой, а
  вертикальная метка покажет место вставки (между чипами, в начало или в
  конец); перетаскивание между чипами меняет порядок. Вынос чипа на холст
  не открепляет мысль.
- **Переход** — клик по чипу: на карте мыслей — фокус и редактор, в
  структурах — мысль открывается в редакторе (и подсвечивается, если есть
  в результатах отбора).
- **Лимит** — не более 20 закреплённых; сверх лимита программа попросит
  сначала открепить лишние.
- Закреплённые хранятся на сервере — на всех ваших компьютерах список один.
  Неактуальные мысли скрываются/показываются вместе с настройкой видимости
  (раздел 7).

### Рабочие столы: Карта мыслей / Структуры мыслей / Хроника

В верхней строке программы, сразу после меню сети, — три кнопки-иконки,
переключающие «рабочие столы» (панель редактора, выделение и статус-бар
остаются общими):

- **Карта мыслей** — холст (этот раздел).
- **Структуры мыслей** — отбор мыслей по критериям (ключевые слова с `*` и
  `-`, типы, свойства, типы связей) и дерево результатов.
- **Хроника** — список всех хронологических комментариев с привязками к
  мыслям и связям.

#### Хроника

- **Панель отбора** (сверху): сохранённые отборы (выбор сразу применяет),
  строка поиска (`*` и `-слово`; ищет в названиях, синонимах и комментариях
  мыслей и связей), поле «Мысли» + флажок «+подчинённые мысли» (до 20
  уровней), типы мыслей, период «с/по», типы связей и способ отбора по
  связям (источники/назначения/оба), сортировка, «Применить» (`Ctrl+Enter`),
  «Очистить отбор», имя отбора + «Сохранить отбор» (повторное имя
  перезаписывает) и «Удалить отбор».
- **Таблица**: колонки С | По | Заголовок | Мысли/связи | Кратко; даты вне
  периода — серые; пагинация по 50 («Записи X–Y из Z»). Навигация стрелками
  по строкам и колонкам, `Tab` — следующая колонка, `Enter` — открыть
  выбранную мысль/связь. Клик по чипу открывает мысль/связь в редакторе.
- **Меню строки** (правый клик): Добавить / Копировать / Удалить.
  **Меню чипа**: Открыть / Отвязать / Связать с… / Добавить к выделению /
  Убрать из выделенных (последние — для мыслей).
- **Перетаскивание**: мысль из выделения/истории/закреплений на строку —
  привязывается к записи, на шапку/пустое место таблицы — создаётся новая
  запись с этой привязкой, на панель отбора — в поле «мысли». Чипы мыслей
  перетаскиваются в выделение и закрепления.
- **Нижняя область** — просмотр/правка записи (как вкладка «Хроника»
  редактора, раздел 4) + чипы всех привязок; ключевые слова отбора
  подсвечены.
- **История вида** — в статус-баре (мысли и связи, открывавшиеся в
  редакторе); очищается при «Применить».

## 3. Добавление мыслей

1. Правый клик по мысли → «Добавить вниз/вверх/налево» — или потяните за
   **верхний эллипс** (создать родителя) / **нижний эллипс** (создать ребёнка)
   облачка — или дважды кликните по пустому месту зоны «Верх слева»
   (родитель) / «Низ» (ребёнок) — или правый клик по этим зонам →
   «Добавить мысль».
2. В диалоге начните вводить название — ETN **ищет существующие мысли** (по
   имени и синонимам), чтобы не плодить дубликаты. Выберите найденную или
   создайте новую.
3. Синонимы вводятся через `|`: `Иванов Иван | Ваня, Иваныч`.
   В синониме можно использовать подстановки `*` — «любое количество любых
   символов в пределах одного слова»: синоним `Игорян*` найдёт мысль при вводе
   `Игорянский`, а `Петров* Игор*` — при вводе `Петрова Игоря` (но не
   `Петрович передал Игорю`).
4. Для нескольких мыслей: включите режим «несколько», вводите по одной (Enter),
   в конце `Ctrl+Enter`. Можно вставить многострочный текст — каждая строка
   станет мыслью. `Ctrl+Shift+Enter` — вставить всё и сразу открыть первую из
   добавленных мыслей в фокусе.
5. Перетаскивание ссылки/файла из браузера в верх-лево или низ холста создаёт
   мысль с вложением.

## 4. Редактор мысли/связи

Панель справа (положение настраивается). В шапке: заголовок, синонимы, тип,
иконка, актуальность, цвета, стиль шрифта. Ниже — вкладки:

- **Основное** — «Свойства» (поля, заданные типом мысли) и постоянный
  комментарий (markdown, просмотр/правка).
- **Вложения (N)** — список ссылок/файлов и область просмотра: картинки —
  просмотр, тексты/markdown — просмотр с правкой, прочее — открытие в системном
  приложении.
- **Связи** — «Прямые связи» (сгруппированы по типам, группы сворачиваются),
  «Упоминания» (где эта мысль упоминается в текстах) и «Использование» (мысли,
  чьи свойства ссылаются на эту мысль).
- **Хроника (N)** — хронологические комментарии: записи с датами начала/конца
  (события, задачи), просмотр и правка прямо на вкладке. Запись может быть
  привязана к нескольким мыслям/связям и видна во вкладке у каждой из них.

Вкладки наполняются только при открытии; счётчики видны в заголовках вкладок.
Клик по линии связи на холсте открывает связь в редакторе.

## 5. Типы мыслей и связей

Раздел «Типы» в меню сети. Тип определяет внешний вид (иконка, цвет, стиль) и
набор свойств. Тип связи — два имени (`name_forward`/`name_reverse`), цвет,
стиль линии. Комментарий типа — подсказка для AI-агентов.

## 6. Совместная работа

- Изменения других участников приходят **без перезагрузки** (WebSocket).
- При одновременной правке одного поля — последняя запись побеждает; конфликт
  показывается уведомлением.
- Индикатор состояния в статус-баре: 🟢 подключено, 🟡 переподключение, 🔴 нет
  связи.

## 7. Неактуальные мысли

Мысль/связь можно пометить неактуальной (контекстное меню → «Изменить
актуальность»). Показ неактуального включается в настройках видимости
(персонально для каждой сети). Настройка действует и на панель закреплённых
мыслей: при скрытии неактуального их чипы прячутся.

## 8. Экспорт

Выделите мысли (Ctrl+клик) → панель слева → меню «Действия» → «Экспорт» →
формат markdown/pdf/html. Документ формируется из заголовков, комментариев и
связей.

## 9. Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+F` | поиск (на карте мыслей) |
| `Ctrl+клик` | добавить/убрать из выделения |
| `Ctrl+клик` по эллипсу | выделить всех родителей/детей |
| `Escape` | закрыть диалог / снять выделение |
| `Ctrl+Enter` | в виде «Хроника» — применить отбор |
| `↑`/`↓`, `←`/`→`, `Tab`, `Enter` | навигация по таблице «Хроники» |
