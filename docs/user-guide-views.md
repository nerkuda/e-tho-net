# Руководство пользователя ETN. Часть 3: обзоры, слои, обмен

[Часть 1: основы и карта мыслей](user-guide.md) ·
[Часть 2: редактор, типы, удаление](user-guide-editing.md)

## 1. Структуры мыслей (рабочий стол)

Отбор мыслей по критериям и дерево результатов — для обзора и массовых
операций.

**Панель отбора** (сверху):

- сохранённые отборы (выбор сразу применяет; имя + «Сохранить отбор» /
  «Удалить отбор»);
- ключевые слова с мини-синтаксисом: слова через пробел (все обязательны),
  `*` — подстановка внутри слова, `-слово` — исключение; чекбоксы, где
  искать — «наименование / синонимы / комментарий»;
- фильтры: типы мыслей, актуальность, «показывать помеченные на удаление»,
  свойства (ключ + оператор + значение), даты создания/изменения;
- «+подчинённые мысли» — направленный обход поддерева выбранной мысли
  (до 20 уровней);
- «Применить» / «Очистить отбор».

**Результаты** — дерево раскрытия: корневые мысли отбора, раскрываются
родитель→дети; связи рисуются кривыми между всеми видимыми мыслями (как на
карте); FLIP-анимация раскрытия/сворачивания. Пустой отбор возвращает HOME и
всех «сирот». Клавиатурная навигация по дереву — как в проводнике (↑/↓,
Tab, ←/→, Ctrl+↑/↓).

- **Клик по мысли** — открыть в редакторе (активная — ореол);
  **двойной клик** — перейти к ней на карте.
- Правый клик по мысли: стандартное меню + «Найти на карте мыслей».
- **Меню «Команды ▾»** — операции над всеми мыслями применённого отбора:
  смена типа, смена актуальности и т.п. (подтверждение показывает число
  затрагиваемых).
- Перетаскивание: мысли из дерева — в выделение, в поля отбора, на холст
  (создание связи); чипы из других панелей — в поле «мысли» отбора.

## 2. Хроника (рабочий стол)

Список всех хронологических комментариев сети с привязками к мыслям и
связям.

- **Панель отбора** (сверху): сохранённые отборы (выбор сразу применяет),
  строка поиска (`*` и `-слово`; ищет в названиях, синонимах и комментариях
  мыслей и связей), поле «Мысли» + флажок «+подчинённые мысли» (до 20
  уровней), типы мыслей, период «с/по», типы связей и способ отбора по
  связям (источники/назначения/оба), сортировка, «Применить» (`Ctrl+Enter`),
  «Очистить отбор», имя отбора + «Сохранить отбор» (повторное имя
  перезаписывает) и «Удалить отбор».
- **Таблица**: колонки С | По | Заголовок | Мысли/связи | Кратко; даты вне
  периода — серые; пагинация по 50 («Записи X–Y из Z»). Навигация стрелками
  по строкам и колонкам, `Tab` — следующая колонка, `Enter` — открыть
  выбранную мысль/связь. Клик по чипу открывает мысль/связь в редакторе.
- **Меню строки** (правый клик): Добавить / Копировать / Удалить.
  **Меню чипа**: Открыть / Отвязать / Связать с… / Добавить к выделению /
  Убрать из выделенных (последние — для мыслей).
- **Перетаскивание**: мысль из выделения/истории/закреплений на строку —
  привязывается к записи, на шапку/пустое место таблицы — создаётся новая
  запись с этой привязкой, на панель отбора — в поле «мысли». Чипы мыслей
  перетаскиваются в выделение и закрепления.
- **Нижняя область** — просмотр/правка записи (как вкладка «Хроника»
  редактора, [часть 2, раздел 1](user-guide-editing.md)) + чипы всех
  привязок; ключевые слова отбора подсвечены.
- **История вида** — в статус-баре (мысли и связи, открывавшиеся в
  редакторе); очищается при «Применить».

## 3. Панель выделения и групповые операции

Панель слева (ширина тянется). Добавление — `Ctrl+клик` по мыслям в любом
виде; перетаскивание мыслей в панель; `Ctrl+клик` по эллипсу облачка
добавляет всех его родителей/детей.

Меню панели:

- **«Выделение»** — очистить, убрать дубликаты, инвертировать (относительно
  текущего отбора «Структур»).
- **«Действия»** — групповые операции: смена типа, актуальности, экспорт
  (раздел 5), удаление ([часть 2, раздел 6](user-guide-editing.md)),
  копирование набора мыслей со связями между ними.
- **«Свойства»** — показать свойства выделенных мыслей.

## 4. Слои изменений

Слой — «прозрачная плёнка» поверх сети: вы работаете, ваши правки не видны
остальным (кроме тех, кто явно переключился в тот же слой), пока слой не
**слит** в родителя. Всё, что слой не перекрыл, показывает текущее состояние
основы — слой не снимок, а copy-on-write ветка. Глубина — до 4 слоёв поверх
основы.

Сценарии: черновые правки без риска для базы, эксперименты, параллельная
работа агента и человека, подготовка переноса большого фрагмента.

### 4.1. Меню слоёв `[▤ Основа ▾]`

Заголовок меню — имя текущего слоя (постоянный индикатор «где я сейчас»):

- список слоёв сети (вложенность — отступом; текущий отмечен галочкой);
  выбор слоя переключает сессию;
- «Создать новый слой…»;
- при выбранном слое: «Отличия от „…“…», «Слить „…“ в „…“…», «Удалить
  „…“…».

**Слой запоминается за табом**: два таба одной сети могут работать в разных
слоях; переключение таба переключает слой. Смена слоя — полный ресинк:
перечитываются фокус, редактор, структуры и хроника в контексте нового слоя.

### 4.2. Создание и работа

Диалог «Новый слой изменений»: название (обязательно), комментарий
(необязательно, но желателен — по нему коллега или AI-агент поймёт назначение
слоя), ветка git (необязательна, просто пометка). Создание сразу переключает
на новый слой.

Все обычные операции (создание/правка/удаление мыслей и связей, типы,
комментарии) работают в слое как обычно — но изменения записываются как
теневые строки слоя. Индикация на карте: перекрытые мыслью — пунктирная
рамка с бейджем слоя в правом верхнем углу, перекрытые связи — штриховая
линия.

Слои подчиняются правилам корзины: мысль, созданная в слое, при «удалить
совсем» удаляется; живая строка основы, перекрытая в слое, может быть только
помечена (удержание основы показывается честной причиной блокировки).

### 4.3. Отличия (диффы)

Диалог «Отличия…» — два представления:

- **«Связи»** — структурный дифф: связи добавлены/удалены, смена типа,
  мысли, сменившие родителя, изменение порядка (свёрнуто пачками).
- **«Содержание»** — построчный текстовый дифф markdown-документов слой ↔
  цель: удалённое красным, добавленное зелёным.

### 4.4. Слияние

«Слить „слой“ в „родителя“» переносит правки слоя в родителя одной
транзакцией. Перед выполнением — подтверждение; успех показывается отчётом
(перенесённые строки по таблицам, пропущенные связи, факт создания
резервного слоя), отказ — списком конфликтов (строка менялась и в слое, и в
родителе после создания слоя) без частичного применения. Резервный
служебный слой хранит прежнее состояние затронутых строк — точка отката
(в списке слоёв не показывается).

Слитые строки покидают слой; сам слой остаётся — его можно удалить или
продолжить в нём работать.

### 4.5. Удаление слоя

Удаляет слой вместе со всеми его слоями-потомками (диалог показывает их
число) и всеми теневыми правками — **основа не пострадает**. Клиенты,
сидевшие на удаляемом слое, автоматически переключаются на родителя. Сразу
после удаления выполняется очистка корзины, которую слой удерживал.

## 5. Экспорт и импорт

Выделите мысли (`Ctrl+клик`) → панель выделения → меню «Действия» →
«Экспорт»:

- **Markdown / HTML** — документ из заголовков, комментариев и связей
  выделенного подграфа (HTML можно распечатать в PDF). Формат PDF пока не
  реализован — используйте HTML + печать браузером.
- **zip-архив (.etnx)** — полный переносной архив мыслесети: диалог параметров
  (что включать — типы, вложения и т.д.).

**Импорт…** (там же) — из `.etnx`/`.zip`: флажки «что импортировать»;
повторный импорт того же файла идемпотентен (дубликаты не создаются).
`.etnx` — способ перенести сеть на другой сервер без доступа к файловой
системе сервера.

Слой может ссылаться на ветку git, а его диффы показывают правки — но
экспорт/импорт `.etnx` работает с основой сети.

## 6. Совместная работа

- Изменения других участников приходят **без перезагрузки** (WebSocket).
- При одновременной правке одного поля — последняя запись побеждает; конфликт
  показывается уведомлением.
- Индикатор состояния в статус-баре: 🟢 подключено, 🟡 переподключение, 🔴 нет
  связи. При пробуждении компьютера/возврате сети соединение
  восстанавливается само.
- Правки другого участника в **другом слое** вам не видны, пока вы не
  переключитесь в него.

## 7. Настройки

Единый диалог: меню «Вид» → «Все настройки» (или «Настройки мыслесети» в меню
сети — сразу на разделе сети). Разделы:

- **Пользователь** — имя для отображения.
- **Мыслесеть** — название сети; самоописание сети (описание, «когда
  использовать», правила, примеры — доступно владельцу; читается
  AI-агентами); «узловой тип раздела» (структура сети для агентов);
  «Видимость» — показывать неактуальные мысли и связи (общая настройка для
  всех ваших клиентов в этой сети).
- **Клиент** — тема (светлая/тёмная), размер облачка и отступ между
  облачками.

Применение — «Применить» (`Shift+Enter`) или «Применить и закрыть»
(`Ctrl+Enter`); отмена — `Esc`.

Административные функции (пользователи, ключи, сети, аудит) — в
[admin-guide.md](admin-guide.md).
