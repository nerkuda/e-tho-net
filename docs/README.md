# ETN — The Endless Thought Network. Спецификации

Комплект проектных спецификаций для системы ETN — бесплатного self-hosted аналога
программы TheBrain.

## Источник истины

Спецификации живут в **мыслесети ETN** (база знаний проекта). Файлы
`01-…-15-*.md` **генерируются** из публикаций мыслесети и обновляются при
выпуске каждой версии; вручную их править нельзя — правка потеряется при
следующей сборке. Изменить спецификацию = изменить мысль в базе знаний
проекта, затем пересобрать комплект.

Сборка комплекта — из слоя изменений ветки релиза, поэтому файлы в `main`
всегда описывают выпущенное состояние системы.

## Принципы проекта

1. **Self-hosted, без внешних зависимостей.** Сервер разворачивается внутри сети
   пользователя, не зависит от облака и платных сервисов.
2. **Минимум технологий.** Node.js + SQLite + WebSocket. Никаких отдельных
   серверов БД, брокеров, кэшей.
3. **Онлайн-only.** Клиент работает только при связи с сервером. Локально хранит
   персональные настройки, UI-state и черновики правок (для защиты от потери при
   разрыве связи).
4. **Мыслесеть как изолированная база.** Каждая мыслесеть — отдельный
   SQLite-каталог `<network_id>/data.db`. Системные данные (пользователи, доступ,
   API-key) — в общей `_system.db`.
5. **Real-time по подписке.** Все изменения пушатся участникам мыслесети через
   WebSocket без перезагрузки.
6. **Ядро без AI, AI через MCP.** Встраивание агентов в ядро не делается.
   Внешние агенты подключаются к ядру через MCP-сервер.
7. **Три уровня доступа:** администратор системы → владелец мыслесети → участник.
