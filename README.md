# ETN — The Endless Thought Network

Бесплатный self-hosted «цифровой мозг»: заметки, идеи, задачи и файлы живут не
в папках, а в виде направленного графа связанных мыслей, который можно
листать, как разум — от общего к частному и обратно. Вдохновлён TheBrain, но
не копирует его, а развивает собственные методики работы с информацией — свой
сервер, свои данные, никаких подписок и облаков.

## Почему ETN, если есть Obsidian и TheBrain

Я много лет вёл базу знаний в Obsidian и TheBrain одновременно. Честный расклад, из которого вырос ETN:

- **Obsidian** — самый лучший заметочник из всех, которые я пробовал. Но
  бесплатная синхронизация — это головная боль. Чтобы понимать смысл ссылок,
  нужно сильно постараться, но в запросах это понимание не используешь. Иметь
  хронику по отдельным заметкам — тоже непросто.
- **TheBrain** подкупает плексом, но не даёт обсидиановской свободы. За типы
  мыслей и свойств нужно платить, но и тогда свойства мыслям не добавишь. А уж
  синхронизировать его без чужого сервера и платной подписки — почти
  нереально.
- **ETN** постарался взять лучшее из обеих программ. В нём мысли могут быть
  реально атомарными и иметь свойства, связи между ними имеют смысл. Данные
  хранятся только там, где решает пользователь, а синхронизация не нужна — вся
  работа в реальном времени.
- **Графовая память для агентов.** В отличие от memory-хранилищ, построенных 
  только под агентов, ETN — база знаний для человека, к которой агенты подключаются
  через MCP. Они ходят по графу связей вместо векторного поиска — и работают с 
  теми же знаниями, что и человек.

Объективное сравнение по возможностям — в
[документации](docs/userdocs/comparison.md).

## Кому это подходит (и кому — нет)

Подойдёт, если вы:

- ведёте базу знаний в файлах и устали, что заметка живёт только в одной папке;
- хотите, чтобы ИИ-агенты работали с вашими знаниями, а не наоборот;
- цените открытый код и контроль над данными;
- есть где держать постоянно включённый сервер — домашний ПК или VPS: без него
  базы знаний не будет;
- разрабатываете собственных ИИ-агентов и ищете для них надёжную память и RAG.

Не подойдёт, если:

- нужен мобильный клиент «здесь и сейчас» (пока только в планах);
- нуждаетесь в автономных копиях базы знаний на каждом компьютере;
- ищете простой заметочник без графовой логики.

## Ключевые возможности

- 🧠 **Граф вместо папок.** Мысль живёт во всех своих контекстах сразу; карта
  показывает выбранную мысль в центре вместе с её окружением.
- 🏷️ **Связи со смыслом.** Типизированные связи-свойства («зависит от», «место
  работы», «доказывает»); типы и онтология — опционально, когда нужны.
- 📝 **Всё внутри мысли.** У любой мысли может быть Markdown-заметка с 
  трансклюзиями, вложения, свойства и хронология.
- 🔍 **Поиск и отборы.** По названиям, текстам, связям и хронике; сложные
  условия сохраняются именованными отборами.
- 📅 **Ежедневник, из которого растут мысли.** Daily notes с привязкой записей
  к мыслям и созданием мыслей из записей.
- 📖 **Публикации.** Связный документ с оглавлением из разрозненных мыслей;
  экспорт в Markdown/HTML/PDF.
- 🗂️ **Слои — ветки для знаний.** Перестройка базы в отдельном слое: слил,
  если понравилось; удалил без следа — если нет.
- 👥 **Совместная работа в реальном времени.** Люди и агенты правят одну базу
  одновременно — с авторством и блокировками.
- 🤖 **Память для AI-агентов.** Встроенный MCP-сервер: агенты ходят по графу
  связей, дописывают и связывают мысли.

Всё это — self-hosted, под MIT, без подписок.

Подробно об этих и других возможностях — в [пользовательской документации](docs/userdocs/overview.md).

## Быстрый старт

От нуля до первой мыслесети — несколько минут, без терминала и без знаний о
серверах.

### Windows — самый простой путь

1. Скачайте установщик `ETN-Setup-<версия>.exe` со страницы
   [релизов проекта](https://github.com/nerkuda/e-tho-net/releases) (последняя
   версия — вверху списка) и запустите.
2. Отметьте компоненты **сервер** и **клиент** — дальше установщик всё сделает
   сам: поставит Node.js и службу Windows, создаст первого администратора.
3. Сохраните показанный **первичный API-ключ**: он демонстрируется только один
   раз и нужен для подключения к серверу.
4. Откройте клиент ETN, подключитесь к серверу по адресу `http://127.0.0.1:4321`
   и используйте сохранённый ключ.
5. Создайте первую мыслесеть — и пользуйтесь: добавляйте мысли, связывайте их,
   ведите ежедневник, делитесь публикациями.

### Linux

Клиент ставится одной командой, без sudo:

```bash
curl -fsSL https://github.com/nerkuda/e-tho-net/releases/latest/download/install.sh | bash
```

Сервер — из архива поставки или Docker-образом: пара команд из
[инструкции по установке](docs/userdocs/install.md).

### macOS

Готовой сборки нет — клиент собирается из исходников:
[инструкция по установке](docs/userdocs/install.md).

Установку с помощью LLM-агента, Docker, systemd, HTTPS, обновление и
резервное копирование —
[`docs/userdocs/install.md`](docs/userdocs/install.md): там все команды,
переменные окружения и типовые ошибки.

## Установка

Коротко о вариантах:

| Платформа | Сервер | Клиент |
|---|---|---|
| Windows | `ETN-Setup-<версия>.exe` — служба + клиент одним пакетом | тем же установщиком |
| Linux | `etn-server-<версия>.tar.gz` (нужен Node.js 22) или Docker-образ `ghcr.io/nerkuda/e-tho-net/etn-server:v<версия>` | `install.sh` одной командой |
| macOS | из исходников | из исходников |

Все сборки — в [релизах проекта](https://github.com/nerkuda/e-tho-net/releases);
скачанное сверяйте с `SHA256SUMS`.

**Подробные инструкции** — все способы установки, обновление (в том числе
сервера-службы прямо из клиента), переменные окружения, бэкапы и
восстановление, доступ по HTTPS — в
[`docs/userdocs/install.md`](docs/userdocs/install.md).

## Неподписанные сборки

Готовые дистрибутивы и установщик ETN пока **не подписаны** сертификатом
разработчика из-за геополитических проблем. Windows и самостоятельно собранное
приложение для macOS могут показывать предупреждения:

- **Windows:** SmartScreen — «Windows protected your PC» (нужно «More info» →
  «Run anyway»); в Windows 11 с включённым Smart App Control запуск
  неподписанного приложения может быть заблокирован.
- **macOS:** готовой сборки в релизе нет — клиент собирают из исходников; если
  вы передаёте собранное приложение другим, Gatekeeper может показать
  «Apple cannot check it for malicious software»; в macOS 15 и новее обходной
  путь — System Settings → Privacy & Security → Open Anyway.
- **Linux:** подпись обычно не требуется; проверяйте SHA-256 архивов по
  `SHA256SUMS` из релиза.

В случае сомнений проверьте исходный код и соберите дистрибутив самостоятельно
 — инструкция в [`docs/userdocs/install.md`](docs/userdocs/install.md).

## Стек

- **Сервер:** Node.js 22 LTS (`.nvmrc`; для него у better-sqlite3 есть готовая prebuilt-binary — на Node 24 потребуется Python в PATH), TypeScript, Fastify, better-sqlite3, WebSocket.
- **Клиент:** Electron, TypeScript.
- **Хранилище:** SQLite — одна `_system.db` + `networks/<id>/data.db` на сеть.
- **MCP:** `@modelcontextprotocol/sdk`.

## Структура монорепо

```
etn/
├── docs/      # спецификации, ADR и пользовательская документация
├── server/    # серверное приложение + CLI (etn init)
├── client/    # десктоп-клиент на Electron
├── shared/    # общие типы (DTO, константы, протоколы real-time)
└── package.json
```

## Разработка

```bash
npm install              # установить зависимости всех workspaces
npm run dev:server       # запуск сервера в режиме разработки
npm run dev:client       # запуск клиента
npm run typecheck        # проверка типов во всех workspaces
npm test                 # все тесты
```
