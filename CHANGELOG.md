# Changelog

Все заметные изменения проекта фиксируются здесь. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.4.0] — 2026-08-24

### Добавлено

- **Табы в одном окне (фаза Q):** несколько мыслесетей одновременно —
  лента табов с переполнением и drag-n-drop, snapshot состояния таба с
  dirty-маркером, realtime-пул соединений, заглушка для недоступных сетей.
- **Экспорт/импорт `.etnx` (фаза P):** формат переносимости ETNX v1.0,
  zip-экспорт мыслесети через диалог, импорт с флажками «что импортировать»,
  слайсы импорта с realtime-событиями, идемпотентность повторных вставок.
- **Wiki-id ссылки `[[#<id>]]` / `[[n:<сеть>#<id>]]` (фаза R):**
  ID-форма вики-ссылок с резолюцией в имена, атомарный блок имени и
  навигация стрелками в редакторе, кросс-сетевая резолюция, протокол
  `etn://open?…` в Electron, контекстное меню «Обновить формат» для
  legacy-ссылок, две подгруппы в «Упоминаниях» таба «Связи»;
  инструмент `etn.thoughts.backlinks` (REST + MCP).
- **MCP-сервер — пакет для AI-агентов (фаза O):** составная запись
  «единицы знания» `etn.thoughts.upsert_bundle` одной транзакцией;
  мульти-привязки в `etn.comments.upsert` (`targets[]`); карта значений в
  `etn.properties.set`; `etn.types.list` с резолвом типа по имени;
  самоописание сети и контекстная типизация (markdown-поля, узловой тип,
  `structure`); предупреждения о незаполненных required-свойствах;
  аннотации инструментов; per-key переопределение rate-limit записи;
  дельта-фид изменений `etn.changes.list`; метрики чтений
  `etn.metrics.reads`; offset в `etn.thoughts.search`; компактная проекция
  ответов `view=compact|full`; мягкий бюджет подграфа (`max_chars`).
- **Копирование и вставка мыслей (L26):** подграф в буфер обмена,
  Ctrl+C/Ctrl+V с видимой обратной связью и поддержкой раскладок, вставка
  между сетями; клипборд срабатывает по мысли под пунктирной рамкой.
- **Ручной порядок мыслей в зонах (L25):** row-major раскладка, индикатор
  позиции, Ctrl+Shift+←/→, чистка manual-списка при перестановке; одно
  вложение в нескольких мыслях + поиск в диалоге добавления.
- **Прочее:** поле «Шаблон комментария» в типах мыслей с автозаполнением;
  единый диалог настроек и self-service `PATCH /me`; «Мыслесеть» во второй
  строке меню; markdown-виджеты полей в настройках мыслесети.

### Исправлено

- Сервер рассылает события, записанные внешними процессами (relay
  `EventLogRelay`, docs/04-realtime §5); импорт `.etnx` идемпотентен
  (INSERT OR IGNORE для связей/комментариев).
- Панель истории: динамическое число облачков (до 25, при переполнении —
  dropdown), обрезка заголовка до 24 символов.
- Размеры/позиция главного окна запоминаются и восстанавливаются
  (`parseBounds` читает width/height) и не перетираются авто-эвентами.
- Wiki-id в редакторе: кеш имён снова находился (networkId поля),
  устранено зависание UI при фокусе комментария, атомарный блок имени.
- Поиск: упоминания матчатся целиком (граница слова, точные словосочетания),
  сниппеты «Ссылок на мысль» показывают имена вместо `[[#<id>]]`, одна
  мысль выводится один раз с подсветкой первого вхождения, иконки и стили
  как в облачках; настройки панели применяются сразу.
- Состав верхних меню переработан («Все настройки» вернулись в «Вид»,
  клик=cursor); подписи флажков видны в диалогах экспорта/импорта; Esc
  отменяет drag облачка; блокированы системные комбинации в полях типов.
- Тесты: EventLogRelay — детерминированные ожидания вместо фиксированных
  (флейк под полным прогоном устранён).

## [0.3.0] — 2026-08-21

### Добавлено

- **«Хроника» — третий рабочий стол:** хронологические комментарии с
  несколькими привязками (мысль/связь), таблица записей с фикс. шапкой,
  панель отбора (период, авторы, мысли, чек-листы типов, ресайзеры);
  клик по мысли в записи открывает её в редакторе.
- **Закреплённые мысли:** панель в тулбаре (чипи́ ≤64 символов,
  переполнение — dropdown, клик — переход к виду, меню, drag-n-drop с
  переупорядочиванием, лимит 20); команды «Закрепить/Открепить» во всех
  меню мыслей; перетаскивание в панель с облачков родственников и фокуса.
- **Иерархические типы мыслей и связей:** наследование вида строк,
  выбор родителя (развёрнутый список, «без родителя»), дерево типов
  отрисовывается с эффективными (наследованными) настройками.
- **«Структуры»:** меню «Команды ▾» над всеми мыслями применённого отбора
  (смена типа/актуальности, диалоги допускают создание мыслей и выбор типа
  связи); фильтр «Актуальность» в «Дополнительно»; команда «Найти на карте
  мыслей» из контекстного меню; связи дерева — кривые как на карте между
  всеми видимыми мыслями; FLIP-анимация раскрытия/сворачивания;
  клавиатурная навигация по дереву как в проводнике (↑/↓/Tab, ←/→,
  Ctrl+↑/↓); панель отбора — компактные поля, диалоги выбора, история
  ключевых слов, пагинация «Показать ещё» по узлу.
- **Навигация по карте:** одиночный клик/Enter открывают мысль в редакторе
  с ореолом, двойной клик — фокус; стрелки/Home/End двигают рамку-курсор
  по видимой геометрии с доскроллом, Ctrl+Enter — фокус, Ctrl+Shift+↑/↓ —
  ручная перестановка, Tab/Shift+Tab работают как →/←.
- **Добавление мыслей из зон:** двойной клик по пустому месту зон
  (верх-лево/низ) и команда «Добавить мысль» в меню зон; Ctrl+Shift+Enter
  в диалоге — вставка с переводом первой добавляемой в фокус.
- **Авто-разметка упоминаний в комментариях:** текст комментария
  подсвечивает названия известных мыслей (внутри wiki-ссылок и владелец
  записи Хроники не выделяются).
- **Поиск по ID мысли:** запрос-UUID в поиске и диалогах добавления/выбора
  идёт напрямую (секция «Мысль по ID», опции поиска игнорируются).
- **Вложения:** кнопка «Открыть с диска…» в диалоге добавления; файл
  грузится на сервер (копия в каталоге сети, mime/размер, предпросмотр) —
  путь без копии больше не создаётся.
- **URL-свойства:** кнопка «Открыть» рядом с полем (http/https, `file://`,
  локальные пути и UNC, зарегистрированные протоколы вроде `obsidian://`;
  опасные схемы отклоняются); URL-картинки в просмотрщике вложений —
  кнопка открытия; ошибки открытия показываются уведомлением.
- **MCP-сервер:** обогащённое чтение мысли (`meta` — счётчики, превью
  постоянного комментария); «Использование» мысли (`usage_count`,
  инструмент и ресурс `usage`); резолв `thought_ref`-значений в `{id,
  title}` и превью комментариев в `subgraph`; каталоги типов в
  read-инструментах; `etn.comments.get` (полный текст), `etn.comments.update`,
  `etn.comments.delete`.
- **Прочее:** мини-синтаксис поиска в диалоге добавления связи (все слова
  AND, `*`, `-слово`; якорь не показывается в найденных); универсальный
  диалог добавления/выбора мыслей на базе диалога добавления; ресайзер
  панели выделения (140–480 px, персист).

### Исправлено

- Каскад удаления мысли/связи чистит полиморфные зависимые строки:
  вложения, значения свойств, комментарии связей (сироты не копятся).
- Обход поддерева — UNION-CTE с дедупликацией вместо path-CTE:
  экспоненциальный рост путей замораживал сервер; «+подчинённые мысли» —
  направленный обход (source→target).
- Файл-вложение удаляется с диска только когда не используется (учтены
  другие вложения с тем же `file_path` и иконки мыслей) — и в диалоге,
  и в каскадной очистке.
- Пустой отбор «Структур» возвращает HOME и всех сирот (мысли без активных
  родительских связей), HOME закреплена первой; отборы снова применяются
  (touch() рекурсивно вызывал себя).
- «Структуры»: клик по эллипсу только раскрывает/сворачивает направление
  (без побочной активации мысли); активная мысль — ореол вокруг облачка;
  подсветка заголовков групп; связи только внутри рамки одного результата,
  всплытие при ховере.
- Карта: Ctrl+клик по мыслям не перерисовывает карту; в пустых зонах —
  зона-зависимые подсказки вместо «нет мыслей».
- Блоки кода переносят строки по ширине поля (без горизонтального
  скролла); mermaid-диаграммы скроллятся.
- Вкладка «Связи» показывает неактуальные сущности по настройке
  «Показывать неактуальное».
- Диалоги: Esc закрывает только верхний (удержание не закрывает
  нижележащие); в списках выбора типов нет корневого типа; клик по
  ▸/▾ не выфильтровывает список; сине-зелёная рамка выделенных облачков,
  отличная от ореола открытой мысли.
- Панель выделения: ресайзер не заезжает внутрь панели, меню-бар
  переносится на новые строки при узкой панели.

## [0.2.0] — 2026-08-18

### Добавлено

- **Markdown-редактор (CodeMirror 6)** вместо textarea: единый рендерер
  `@etn/markdown` (сервер + клиент), live preview со скрытием синтаксиса и
  блочными виджетами (код, картинки, таблицы, wiki-ссылки, hr), wiki-ссылки
  `[[имя|алиас]]` с автокомплитом по мыслям сети, mermaid-диаграммы,
  подсветка fenced-кода (CM6 в редакторе, highlight.js в просмотре).
- **Иконки мыслей:** диалог иконок — все эмодзи с группами и вкладка «Файл»
  с иконками типов; иконка из файла-вложения с превью (Ctrl+наведение —
  оригинал).
- **Перетаскивание облачков:** мышиный жест вместо HTML5 DnD (Alt/Ctrl больше
  не перехватываются браузером); Ctrl — переподчинение мысли одной связью;
  Ctrl+Shift — ручное упорядочивание с живым превью вставки и FLIP; раскладка
  зон по столбцам (column-major).
- **Составные имена мыслей:** вне фокуса скрываются части, совпадающие с
  именами видимых связанных мыслей (в том числе вложенные совпадения).
- **Диалог добавления мысли:** типы над вводом, список найденных под ним
  (иконки, оформление, имя родителя); выбор кандидата Tab/стрелками/Enter/
  кликом; Shift+Enter подставляет имя выбранной мысли; типы в одну строку.
- **Черновики полей:** одна строка на поле (upsert по ключу), восстановление
  только в нетронутое поле, вычистка после успешного сохранения.
- **Поиск и упоминания:** заголовки и синонимы матчатся целиком (фразой),
  синонимы с символами подстановки `*`; в упоминаниях один элемент на
  мысль/связь.
- **Типы мыслей и связей:** имена уникальны регистронезависимо (409
  DUPLICATE), живая проверка в редакторах.
- **MCP-сервер:** `etn.thoughts.query` — структурная выборка мыслей за один
  вызов.
- **Realtime:** сервер рассылает события, записанные внешними процессами
  (event-log relay).
- **Прочее:** ID мысли в редакторе с командой «Копировать ID»; лого и favicon;
  Ctrl+Enter подтверждает диалоги, Esc закрывает; клавиатурная навигация в
  диалоге выбора мысли; линии связей крепятся к внешним границам эллипсов;
  hover эллипса подсвечивает все его связи; единая типографика markdown в
  редактировании и просмотре.

### Исправлено

- Открытие сети: начальная мысль ищется по флагу `is_root`, а не по названию
  HOME; секции «Основного» не дублируются при повторном открытии; сеть снова
  открывается после повторного применения миграции 016b.
- Черновики: заголовок не затирает свежее значение поля; debounce с опоздавшим
  id не оставляет мусор после сохранения.
- Упоминания без дублей; удалённая мысль уходит из результатов поиска.
- Перетаскивание: Ctrl+Shift-упорядочивание срабатывает при броске (превью
  WYSIWYG), эллипсы не перехватывают жест как Ctrl+клик.
- Локальные правки мысли (тип/актуальность/иконка/стиль) сразу перерисовывают
  облачко и обновляют редактор и структуры во всех рабочих местах.
- Эллипсы центрированы по ширине облачка; высота облачков по содержимому.
- Live preview: переносы строк, маркеры блоков, рамка цитат, отступы
  заголовков (стрелки не прыгают через строки).
- Список выбора типа не зависает после перерисовки и не закрывается при
  прокрутке; Tab не теряет фокус.
- Зона «братья» сортируется по сохранённому преференсу пользователя.
- При перетаскивании интернет-ссылки мысль получает название и иконку сайта.

## [0.1.0] — MVP (в разработке)

### Добавлено

- **Сервер (Node.js + Fastify + SQLite):**
  - хранение: одна `_system.db` (пользователи, ключи, реестр сетей, аудит,
    event_log) + отдельный `data.db` на каждую мыслесеть;
  - аутентификация по статическим API-key (`etn_<32hex>`, только SHA-256 хеш);
  - роли: администратор системы / владелец сети / участник (равноправный);
  - REST API `/api/v1`: пользователи и ключи, сети и членство, мысли, связи,
    типы мыслей/связей и свойства, комментарии (постоянные/хронологические),
    вложения, полнотекстовый поиск (FTS5), экспорт markdown/html;
  - real-time через WebSocket: каталог событий, `audience: network|user`,
    resume по `last_seq`, подавление эха, идемпотентность по `Client-Request-Id`;
  - MCP-сервер (stdio + StreamableHTTP): 10 ресурсов `etn://`, 19 инструментов,
    4 prompt-шаблона, лимиты и аудит действий агентов;
  - защита от зацикливания обхода графа (visited-set + path-CTE, лимиты).
- **Десктоп-клиент (Electron):**
  - холст с виртуальной сеткой и фиксированными облачками, фокус-облачко,
    эллипсы-индикаторы, SVG-линии связей;
  - редактор мысли/связи (свойства, markdown-комментарии, вложения, упоминания);
  - поиск с четырьмя группами и фильтрами, диалог добавления с дедупликацией,
    история фокуса в статус-баре (50 мыслей), выделение и групповые операции;
  - админ-панель (пользователи, ключи, сети, аудит);
  - локальное хранилище: профили серверов (safeStorage), UI-state, черновики,
    история фокуса, `client_id`, `last_seq`;
  - применение real-time событий к UI без перезагрузки.
- **Инфраструктура:** npm workspaces (server/client/shared), ESLint + Prettier,
  CI (GitHub Actions), Dockerfile + docker-compose, документация
  (install-server, install-client, admin-guide, user-guide, mcp-clients).

### Известные ограничения MVP

- Онлайн-only клиент (офлайна нет; черновики защищают от потери при обрыве).
- Вложения — ссылки/пути; загрузка файлов на сервер не реализована.
- Экспорт в PDF не реализован (HTML + печать).
- Присутствие пользователей (`presence.*`) не отображается в UI.
- Один серверный процесс; WAL-лок SQLite (2–5 одновременных редакторов на сеть).
