# Changelog

Все заметные изменения проекта фиксируются здесь. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.2.0] — 2026-08-18

### Добавлено

- **Markdown-редактор (CodeMirror 6)** вместо textarea: единый рендерер
  `@etn/markdown` (сервер + клиент), live preview со скрытием синтаксиса и
  блочными виджетами (код, картинки, таблицы, wiki-ссылки, hr), wiki-ссылки
  `[[имя|алиас]]` с автокомплитом по мыслям сети, mermaid-диаграммы,
  подсветка fenced-кода (CM6 в редакторе, highlight.js в просмотре).
- **Иконки мыслей:** диалог иконок — все эмодзи с группами и вкладка «Файл»
  с иконками типов; иконка из файла-вложения с превью (Ctrl+наведение —
  оригинал).
- **Перетаскивание облачков:** мышиный жест вместо HTML5 DnD (Alt/Ctrl больше
  не перехватываются браузером); Ctrl — переподчинение мысли одной связью;
  Ctrl+Shift — ручное упорядочивание с живым превью вставки и FLIP; раскладка
  зон по столбцам (column-major).
- **Составные имена мыслей:** вне фокуса скрываются части, совпадающие с
  именами видимых связанных мыслей (в том числе вложенные совпадения).
- **Диалог добавления мысли:** типы над вводом, список найденных под ним
  (иконки, оформление, имя родителя); выбор кандидата Tab/стрелками/Enter/
  кликом; Shift+Enter подставляет имя выбранной мысли; типы в одну строку.
- **Черновики полей:** одна строка на поле (upsert по ключу), восстановление
  только в нетронутое поле, вычистка после успешного сохранения.
- **Поиск и упоминания:** заголовки и синонимы матчатся целиком (фразой),
  синонимы с символами подстановки `*`; в упоминаниях один элемент на
  мысль/связь.
- **Типы мыслей и связей:** имена уникальны регистронезависимо (409
  DUPLICATE), живая проверка в редакторах.
- **MCP-сервер:** `etn.thoughts.query` — структурная выборка мыслей за один
  вызов.
- **Realtime:** сервер рассылает события, записанные внешними процессами
  (event-log relay).
- **Прочее:** ID мысли в редакторе с командой «Копировать ID»; лого и favicon;
  Ctrl+Enter подтверждает диалоги, Esc закрывает; клавиатурная навигация в
  диалоге выбора мысли; линии связей крепятся к внешним границам эллипсов;
  hover эллипса подсвечивает все его связи; единая типографика markdown в
  редактировании и просмотре.

### Исправлено

- Открытие сети: начальная мысль ищется по флагу `is_root`, а не по названию
  HOME; секции «Основного» не дублируются при повторном открытии; сеть снова
  открывается после повторного применения миграции 016b.
- Черновики: заголовок не затирает свежее значение поля; debounce с опоздавшим
  id не оставляет мусор после сохранения.
- Упоминания без дублей; удалённая мысль уходит из результатов поиска.
- Перетаскивание: Ctrl+Shift-упорядочивание срабатывает при броске (превью
  WYSIWYG), эллипсы не перехватывают жест как Ctrl+клик.
- Локальные правки мысли (тип/актуальность/иконка/стиль) сразу перерисовывают
  облачко и обновляют редактор и структуры во всех рабочих местах.
- Эллипсы центрированы по ширине облачка; высота облачков по содержимому.
- Live preview: переносы строк, маркеры блоков, рамка цитат, отступы
  заголовков (стрелки не прыгают через строки).
- Список выбора типа не зависает после перерисовки и не закрывается при
  прокрутке; Tab не теряет фокус.
- Зона «братья» сортируется по сохранённому преференсу пользователя.
- При перетаскивании интернет-ссылки мысль получает название и иконку сайта.

## [0.1.0] — MVP (в разработке)

### Добавлено

- **Сервер (Node.js + Fastify + SQLite):**
  - хранение: одна `_system.db` (пользователи, ключи, реестр сетей, аудит,
    event_log) + отдельный `data.db` на каждую мыслесеть;
  - аутентификация по статическим API-key (`etn_<32hex>`, только SHA-256 хеш);
  - роли: администратор системы / владелец сети / участник (равноправный);
  - REST API `/api/v1`: пользователи и ключи, сети и членство, мысли, связи,
    типы мыслей/связей и свойства, комментарии (постоянные/хронологические),
    вложения, полнотекстовый поиск (FTS5), экспорт markdown/html;
  - real-time через WebSocket: каталог событий, `audience: network|user`,
    resume по `last_seq`, подавление эха, идемпотентность по `Client-Request-Id`;
  - MCP-сервер (stdio + StreamableHTTP): 10 ресурсов `etn://`, 19 инструментов,
    4 prompt-шаблона, лимиты и аудит действий агентов;
  - защита от зацикливания обхода графа (visited-set + path-CTE, лимиты).
- **Десктоп-клиент (Electron):**
  - холст с виртуальной сеткой и фиксированными облачками, фокус-облачко,
    эллипсы-индикаторы, SVG-линии связей;
  - редактор мысли/связи (свойства, markdown-комментарии, вложения, упоминания);
  - поиск с четырьмя группами и фильтрами, диалог добавления с дедупликацией,
    история фокуса в статус-баре (50 мыслей), выделение и групповые операции;
  - админ-панель (пользователи, ключи, сети, аудит);
  - локальное хранилище: профили серверов (safeStorage), UI-state, черновики,
    история фокуса, `client_id`, `last_seq`;
  - применение real-time событий к UI без перезагрузки.
- **Инфраструктура:** npm workspaces (server/client/shared), ESLint + Prettier,
  CI (GitHub Actions), Dockerfile + docker-compose, документация
  (install-server, install-client, admin-guide, user-guide, mcp-clients).

### Известные ограничения MVP

- Онлайн-only клиент (офлайна нет; черновики защищают от потери при обрыве).
- Вложения — ссылки/пути; загрузка файлов на сервер не реализована.
- Экспорт в PDF не реализован (HTML + печать).
- Присутствие пользователей (`presence.*`) не отображается в UI.
- Один серверный процесс; WAL-лок SQLite (2–5 одновременных редакторов на сеть).
